#  O Mistério da Mansão Lakeview

O Mistério da Mansão Lakeview é um jogo de investigação que estou desenvolvendo em Python, utilizando a biblioteca Tkinter para criar a interface gráfica.

A história acompanha o Sr. S, um investigador que chega a uma antiga mansão cheia de mistérios. Ao explorar os ambientes, o jogador encontra pistas e precisa prestar atenção aos detalhes para descobrir o que está acontecendo.

Comecei esse projeto para praticar programação de uma forma diferente, criando algo meu enquanto aprendo novos conceitos.

##  Sobre o desenvolvimento

Estou cursando Análise e Desenvolvimento de Sistemas e este é um dos meus projetos de estudo em Python.

A ideia é desenvolver o jogo aos poucos, aplicando o que aprendo sobre lógica de programação, funções, estruturas condicionais e interfaces gráficas.

Até agora, implementei:

- Interface gráfica com Tkinter.
- Navegação pela história através de botões.
- Alteração dos textos conforme as escolhas do jogador.
- Exploração inicial da mansão e da sala de estar.
- Leitura e coleta de uma carta misteriosa.
- Um inventário inicial para consultar pistas coletadas.

## Tecnologias utilizadas

- Python — desenvolvimento da lógica do jogo.
- Tkinter— criação das janelas, textos e botões.

## ▶️ Como executar

Para testar o jogo, é necessário ter o Python instalado no computador, com suporte ao Tkinter.

1. Baixe os arquivos deste repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `main.py` pelo terminal:

```bash
python main.py
```
